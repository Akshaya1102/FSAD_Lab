How This Demo Works

Bidirectional Communication: Both client and server can send messages at any time.

Chat: Messages are broadcast to ALL connected clients (open multiple browser tabs to test).

Ping/Pong: Client sends ping, server immediately responds with pong.

Echo: Server receives your text and sends back the reversed version.

Server Broadcast: Server sends heartbeat messages every 30 seconds to all clients.

Notifications: Server notifies all clients when someone joins or leaves.
